CoreCraft Pay Security

Security definiert die technischen Regeln und Grenzen für einen sicheren CoreCraft-Pay-Produktbereich.

Bereich ansehen CoreCraft Pay Übersicht
ACTIVE CORECRAFT PAY AREA

Sicherheit durch klare Grenzen

Statische Produktseiten dokumentieren Funktionen und Architektur. Sensible Zahlungsinformationen und vertrauliche Zugangsdaten gehören nicht in statische Dateien.

Product Components

Kernbereiche

CONTROL 01

Data Boundary

Trennt öffentliche Produktinformationen von sensiblen Zahlungsdaten.

CONTROL 02

Secret Protection

Verhindert die Aufnahme von Zugangsdaten und geheimen Werten in das Repository.

CONTROL 03

Input Validation

Definiert die Prüfung von Daten vor einer technischen Verarbeitung.

CONTROL 04

Route Audit

Prüft erwartete lokale und veröffentlichte Produktadressen.

CONTROL 05

Asset Integrity

Kontrolliert erwartete Dateien sowie CSS- und JavaScript-Referenzen.

CONTROL 06

Change Trace

Macht Änderungen über Git-Historie und vollständige Audits nachvollziehbar.

PRINCIPLES

Grundsätze

  • Keine Speicherung sensibler Zahlungsdaten in statischen Seiten
  • Keine Zugangsdaten oder Geheimnisse im Repository
  • Validierung aller veröffentlichten JSON-Dateien
  • Klare Trennung zwischen Dokumentation und Transaktionssystem
  • Kontrollierte Revisionen über Git und lokale Audits
